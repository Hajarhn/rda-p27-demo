Governing the data dictionary, not the spreadsheet.

A read-only demo of a web-based tool for keeping a research data dictionary accurate, searchable, and shared. It holds descriptions of variables only, never participant data.

Open the demo → What is it?

One shared dictionary

Browse variables by instrument and search by name, so the whole team reads the same definitions instead of scattered spreadsheet copies.

Every change recorded

Each variable keeps a change history, so anyone can see how a definition or code evolved and when.

Standards-aware

Variables carry their definitions, value codes, units, and the standard terms they map to (SNOMED CT, LOINC).

Why it matters

A data dictionary is the reference everyone depends on, yet in most projects it lives in a shared spreadsheet edited by many hands. Rows get overwritten, definitions drift, and no one can say who changed what. Those errors surface late, during reuse, when they cost the most. Treating the dictionary as something worth governing is a simple change that prevents them.
